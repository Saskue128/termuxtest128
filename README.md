# 🎶 Simple Telegram Music Bot

A basic music bot for Telegram voice chats using **Pyrogram** + **PyTgCalls**.

## 🚀 Features
- Play music from YouTube (`/play <song name>`)
- Leave voice chat (`/leave`)
